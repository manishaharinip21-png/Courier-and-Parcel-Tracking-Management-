# Project Overview
**Title:** Courier and Parcel Tracking Management System

**Problem:** Manual parcel records can make it difficult to manage customer details, parcel bookings, delivery assignments and shipment status.

**Objectives:** Centralize customer and delivery-personnel records, register parcels, generate tracking references, track manually updated shipment status, record delivery attempts and analyze shipment data.

**Modules:** Customer Management; Delivery Personnel Management; Parcel Booking; Parcel Tracking; Delivery Attempts; Dashboard; Python Analytics.

**Technology mapping:** Java Swing for UI, JDBC for database connectivity, PostgreSQL for storage, Maven for build management, Python/Pandas/NumPy/Matplotlib for analysis.
